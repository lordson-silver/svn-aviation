📋 How to install this signature

Gmail: Settings → See all settings → General → Signature → Create new → copy the signature from the white box above and paste.

Outlook (desktop): File → Options → Mail → Signatures → New → copy the signature from the white box above and paste.

Apple Mail: Preferences → Signatures → copy the signature from the white box above and paste into the signature preview area.

Personalise: You can directly edit the text in your email client after pasting to change the name, title, and phone numbers.
